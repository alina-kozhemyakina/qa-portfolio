# SQL Testing

## О проекте

Учебный проект по использованию SQL для проверки данных в реляционной базе данных.

Цель проекта — продемонстрировать практические навыки работы с SQL, необходимые для ручного тестирования (Manual QA).

## Цели тестирования

- Получение и фильтрация данных.
- Проверка корректности и целостности данных.
- Поиск записей по заданным условиям.
- Проверка связей между таблицами.
- Выявление потенциальных проблем с данными.

## Структура проекта

- `README.md` — описание проекта.
- `schema.sql` — создание таблиц и тестовые данные.
- `queries.sql` — SQL-запросы с комментариями.
- `test-cases.md` — тестовые сценарии и ожидаемые результаты.

## Структура базы данных

Проект включает три таблицы:

- `customers` — информация о покупателях.
- `orders` — информация о заказах.
- `products` — информация о товарах.

Связь между таблицами `customers` и `orders`:

`customers.id = orders.customer_id`

## Используемые SQL-команды

- `SELECT`, `WHERE`, `AND`, `OR`
- `ORDER BY`, `DISTINCT`
- `IN`, `BETWEEN`, `LIKE`
- `IS NULL`, `IS NOT NULL`
- Агрегатные функции: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`
- `GROUP BY`, `HAVING`
- `INNER JOIN`, `LEFT JOIN`
- `COALESCE`
- `EXISTS`, `NOT EXISTS`
- Подзапросы
- Условные выражения `CASE WHEN`

## Примеры QA-проверок

- Поиск заказов по заданным условиям и диапазонам значений.
- Проверка корректности статусов заказов.
- Проверка наличия связанных записей между таблицами.
- Поиск покупателей без заказов.
- Проверка уникальности значений и поиск возможных дубликатов.
- Подсчёт количества и суммы заказов.
- Проверка средних, минимальных и максимальных значений.
- Поиск записей с отсутствующими значениями (`NULL`).
- Проверка отрицательных сумм и цен.
- Проверка целостности данных и связей между таблицами.
