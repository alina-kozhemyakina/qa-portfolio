# SQL Testing — Test Cases

## О проекте

Набор тест-кейсов для проверки SQL-запросов из файла `queries.sql` на учебной базе данных PostgreSQL.

Тестовые данные создаются скриптом `schema.sql`. Все ожидаемые результаты относятся к исходным данным из этого скрипта.

## Предварительные условия

1. Созданы таблицы `customers`, `orders` и `products`.
2. В таблицы загружены тестовые данные из `schema.sql`.
3. Запросы выполняются в PostgreSQL.

## Дополнительные пояснения

- `COUNT(*)` считает строки результата, а `COUNT(column)` — только строки, где указанное поле не равно `NULL`. Поэтому при `LEFT JOIN` для покупателя без заказов `COUNT(*)` может быть равен 1, а `COUNT(orders.id)` — 0.
- `WHERE` фильтрует строки до группировки, а `HAVING` — группы после `GROUP BY`.
- `BETWEEN` включает обе границы диапазона.
- `EXISTS` проверяет наличие хотя бы одной подходящей записи.
- `NOT EXISTS` может вернуть покупателя, у которого вообще нет заказов, если не задано дополнительное условие.
- `COALESCE` заменяет `NULL` указанным значением, в этом проекте — нулём.
- Проверки отрицательных сумм, отрицательных цен и отсутствующих связанных покупателей полезны для анализа данных из источников без ограничений целостности. В учебной схеме такие ситуации предотвращаются ограничениями `CHECK` и внешним ключом.
