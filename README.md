## Projects

### 1. API Testing — Petstore

Практический проект по тестированию REST API на примере Petstore.

**Что входит в проект:**
- Проверка API-запросов с помощью Postman.
- Работа с HTTP-методами и статус-кодами.
- Проверка структуры и содержимого JSON-ответов.
- Проверка позитивных и негативных сценариев.
- Документирование результатов тестирования.

[View API Testing project](./API-Testing-Petstore/)

### 2. SQL Testing

Учебный проект по использованию SQL для проверки данных в реляционной базе данных PostgreSQL.

**Что входит в проект:**
- Создание таблиц и тестовых данных.
- Написание SQL-запросов для выборки и фильтрации данных.
- Использование JOIN, GROUP BY, HAVING и подзапросов.
- Проверка связей и целостности данных.
- Поиск NULL-значений и возможных дубликатов.
- Подготовка тест-кейсов с ожидаемыми результатами.

[View SQL Testing project](./SQL-Testing/)
